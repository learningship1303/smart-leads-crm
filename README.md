# Smart Leads CRM Dashboard

A modern Full Stack CRM (Customer Relationship Management) Dashboard built using React, TypeScript, Node.js, Express.js, MongoDB, and JWT Authentication.

This project allows businesses to manage leads efficiently with authentication, analytics, filtering, role-based access, and dashboard visualizations.

---

# Live Features

## Authentication System
- User Registration
- User Login
- JWT Authentication
- Protected Routes
- Persistent Login using LocalStorage

---

# Lead Management Features

## CRUD Operations
- Create Leads
- Read Leads
- Update Leads
- Delete Leads
